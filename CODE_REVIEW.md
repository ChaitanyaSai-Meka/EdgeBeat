# EdgeBeat Code Review

Date: 2026-08-25

## Scope

This is a second review of the current working tree, including its uncommitted
changes. The previous review was checked against the new implementation rather
than carried forward unchanged.

## Findings

No unresolved findings remain in the reviewed working tree.

The previously tracked `EdgeBeat.zip` archive is now intentionally generated by
`scripts/package-release.sh`, ignored by Git, validated in CI, and uploaded by
the tagged release workflow.

## Resolved Since Previous Review

- `NowPlayingMonitor` now invalidates poll generations on `stop()` and checks
  `isRunning` before publishing a poll result.
- AppleScript cache access and execution are serialized through
  `appleScriptQueue`.
- Audio capture and analysis now use session generations, reset analyzer state,
  and suppress stale feature callbacks.
- Artwork uses revisions and a metadata-aware cache key, and palette extraction
  reacts to artwork replacement.
- MediaRemote helper processes now have termination timeouts.
- Audio-tap setup rolls back partially created Core Audio resources on failure.
- Invalid sample rates are rejected before analysis.
- A test target and CI workflow were added.

## Remaining Test Risk

The application target passes `swift build`. Local `swift test` cannot run in
the current environment because the installed standalone Swift toolchain does
not provide `XCTest` (`no such module 'XCTest'`). The repository documentation
correctly notes that full Xcode or the macOS CI runner is required for tests.

The new tests cover generation invalidation, artwork revisions/cache identity,
sample-rate validation, ended audio sessions, Spotify duration normalization,
and MediaRemote timeout behavior. macOS runtime coverage is still needed for
Thread Sanitizer checks around Core Audio callbacks, AppleScript execution, and
display sleep/wake transitions.

## Verification Performed

- `swift build`: passed.
- `git diff --check`: passed.
- `swift test`: blocked by the local toolchain missing `XCTest`; CI is configured
  to run it on `macos-14`.

## Overall Assessment

The second revision addresses the stability issues identified previously,
adds useful focused tests plus macOS CI, and now has a reproducible release
archive workflow. The highest-value follow-up is runtime testing of the Core
Audio and private macOS UI paths.
