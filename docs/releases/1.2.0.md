# EdgeBeat 1.2.0

Released: 2026-08-22

EdgeBeat 1.2.0 adds a dedicated companion Now Playing window for a larger,
music-focused listening experience.

## Companion Now Playing Window

- Added a dedicated native window that can be opened from the menu bar.
- Added large album artwork with an album-derived background treatment.
- Added track title, artist, album, progress, remaining time, shuffle, previous,
  play/pause, next, and output-device controls.
- Added a full-screen button and support for the standard macOS full-screen
  window control.
- Keeps the existing playback and audio-analysis pipeline connected while the
  window is open, even if edge lighting is disabled.
- Keeps the display awake while music is actively playing in the companion
  window.

## Compatibility

EdgeBeat 1.2.0 requires macOS 14.4 or later and continues to support Spotify and
Apple Music through the existing metadata and audio-capture pipeline.

The companion window uses the existing playback command path, so its controls
follow the same player permissions and source-selection behavior as the
lock-screen card.
