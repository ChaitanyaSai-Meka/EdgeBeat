# EdgeBeat 1.3.0

Released: 2026-09-09

EdgeBeat 1.3.0 refines the companion Now Playing window into a more immersive
lyrics-focused listening experience, with an Apple Music-inspired two-column
layout and improved lyric rendering.

## Lyrics Experience

- Added an immersive wide layout with centered album artwork and playback
  controls on the left and a transparent lyric rail on the right.
- Made the current synced lyric the visual focus with bright text, while nearby
  and distant lines progressively fade into the background.
- Added smooth automatic lyric scrolling that keeps the active line centered
  during playback.
- Added manual lyric scrolling with a jump-to-current control when browsing
  away from the active line.
- Improved compact-window behavior with a small artwork and metadata header
  above the lyrics.
- Kept click-to-seek support for timestamped lyrics and retained plain-lyrics
  support when synchronized timestamps are unavailable.
- Improved multiline lyric sizing and spacing so long lines remain readable
  without fixed-height clipping.

## Artwork And Layout

- Increased the visibility and saturation of album artwork in the ambient
  companion-window background while preserving lyric contrast.
- Improved artwork sizing, vertical centering, and spacing between the artwork,
  metadata, progress bar, and controls.
- Simplified the wide lyric presentation by removing the heavy panel treatment,
  header badge, and per-line progress indicator.
- Refined the side controls so shuffle, previous, play/pause, next, and utility
  actions remain balanced at different window sizes.

## Companion Full Screen

- Added a native application menu for the companion window so macOS can manage
  menu-bar presentation while an accessory-style EdgeBeat process is full screen.
- Preserved the standard macOS auto-hide behavior: move the pointer to the top
  edge to reveal the menu bar and the EdgeBeat status item.
- Prepared the application policy before the full-screen transition and restored
  the menu-bar-only policy after exit or a failed transition.

## Lock Screen Playback

- Made the lock-screen progress bar interactive for both Spotify and Apple Music.
- Added click-and-drag seeking with immediate position feedback while the player
  confirms the requested position.
- Added accessible playback-position adjustments in ten-second increments.

## Lyrics Reliability

- Improved LRC parsing for UTF-8 byte-order marks and `offset` metadata.
- Added validation for non-finite timestamp values and normalized adjusted
  timestamps safely.
- Included the normalized recording duration in the lyrics cache identity so
  different edits with the same title, artist, and album do not share results.
- Cancelled an in-flight lyrics lookup when the lyrics view is hidden, while
  retaining completed results for fast reopening.
- Excluded blank lyric rows from the synchronized playback viewport.
- Added coverage for lyric timeline boundaries and visible-line filtering.

## Compatibility

EdgeBeat 1.3.0 requires macOS 14.4 or later and continues to support Spotify and
Apple Music through the existing metadata, playback-control, and audio-capture
pipeline. Lyrics are requested only after the Lyrics control is selected and
use the current track title, artist, album, and duration to query LRCLIB. The
application does not bundle or persist a lyrics database. Results remain
limited to the line-level timestamps supplied by that service; word-level
karaoke timing is not available.

The companion window remains a menu-bar-only utility outside full screen. During
native full screen it temporarily provides the application menu required for
macOS's normal menu-bar reveal behavior, then returns to accessory mode when the
window exits full screen.
