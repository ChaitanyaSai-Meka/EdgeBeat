# EdgeBeat 1.1.0

Released: 2026-08-17

EdgeBeat 1.1.0 expands the original edge-lighting experience with a continuous,
music-reactive perimeter wave, a more capable lock-screen player, and lower
background resource usage.

## Highlights

- Added Wave Flow, a single continuous glowing segment that travels around the
  complete display perimeter and transitions smoothly through corners.
- Added wave length and intensity controls with discrete Slow, Medium, and Fast
  speed presets.
- Improved music response so speed, brightness, and wave shape react to captured
  audio without breaking the continuous perimeter path.
- Added deeper album-derived colors while retaining custom single-color and
  gradient modes.
- Made Glow and Wave Flow mutually exclusive so each visual mode remains clear.

## Lock Screen

- Refined the lock-screen now-playing card with larger rounded styling that fits
  the macOS lock-screen presentation.
- Added previous, play/pause, next, and shuffle controls.
- Added the current audio-output route beside the playback controls.
- Positioned the card above the authentication area to avoid covering password
  entry.
- Added display-sleep prevention while the Mac is locked and music is actively
  playing. The assertion is released whenever playback stops or the card is no
  longer active.

## Playback And Audio

- Improved Spotify and Apple Music metadata handling through the bundled
  MediaRemoteAdapter and player fallbacks.
- Added player-specific Core Audio capture with a system-audio fallback.
- Improved album-artwork updates and automatic player selection.

## Efficiency

- Added adaptive 60 FPS and 30 FPS animation timing based on macOS Low Power
  Mode.
- Reduced repeated wave-profile and color work during rendering.
- Stopped Wave Flow animation work whenever the effect is inactive.
- Improved overlay refresh behavior to reduce unnecessary CPU, memory, and
  battery use.

## Application

- Added `Check for Updates...`, which compares the installed version with the
  latest GitHub release.
- Added the application version to the bottom of the menu.
- Improved menu organization and color-selection controls.
- Updated release installation, update, permission, and troubleshooting
  documentation.

## Installation Notes

EdgeBeat 1.1.0 requires macOS 14.4 or later. The release is ad-hoc signed and is
not notarized, so downloaded builds may need the quarantine attributes cleared:

```sh
xattr -r -c /Applications/EdgeBeat.app
```

The lock-screen card relies on private macOS SkyLight APIs. Its behavior may
change after a macOS update.
