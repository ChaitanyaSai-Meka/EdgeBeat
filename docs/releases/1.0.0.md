# EdgeBeat 1.0.0

Released: 2026-08-16

EdgeBeat 1.0.0 is the initial open-source release of the macOS menu-bar
application.

## Highlights

- Added click-through edge lighting that remains visible over full-screen apps
  and across macOS Spaces.
- Added Spotify and Apple Music detection with real system-audio analysis.
- Added album-art palette extraction and custom single-color or gradient modes.
- Added adjustable glow intensity and thickness.
- Added built-in, main, and all-display targeting.
- Added notch-aware rendering for supported MacBook displays.
- Added an interactive lock-screen now-playing card with artwork, progress, and
  playback controls.
- Added persistent preferences and optional Launch at Login.
- Shipped as a menu-bar-only application without a Dock icon.

## Compatibility Notes

- Requires macOS 14.4 or later.
- Uses the bundled MediaRemoteAdapter framework for system Now Playing access.
- Uses private macOS SkyLight behavior for lock-screen window placement.
- Release builds are ad-hoc signed and are not notarized by Apple.
