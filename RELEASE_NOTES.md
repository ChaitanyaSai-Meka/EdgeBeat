# EdgeBeat Release Notes

This document indexes the published EdgeBeat releases. Detailed notes are kept
in separate files so each GitHub release can link to a stable, version-specific
record.

## Current Release

### [EdgeBeat 1.1.0](docs/releases/1.1.0.md) - 2026-08-17

Introduces the continuous perimeter Wave Flow, richer lock-screen controls,
in-app update checking, and power-efficiency improvements.

## Previous Releases

### [EdgeBeat 1.0.0](docs/releases/1.0.0.md) - 2026-08-16

Initial open-source release of the EdgeBeat macOS menu-bar application.

## Downloads

Release builds are published on the official
